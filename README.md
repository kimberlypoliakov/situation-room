# חדר מצב

דף מצב בעברית: ישראל והאזור, אירועים משמעותיים בעולם וסייבר עולמי.
GitHub Actions מריץ את `run.py` כל 15 דקות, ו-GitHub Pages מציג את התוצאה. אין צורך במפתחות.

- `collector.py`: ישראל והאזור (התרעות, טיסות, שווקים, ים, אינטרנט באיראן, חדשות וטלגרם)
- `world.py`: חדשות עולם, אסונות, רעידות, מדדים עולמיים וסייבר
- `run.py`: סבב מלא, כולל תרגום לעברית והיסטוריה של 10 ימים
- `index.html`, `global.js`, `global.css`: האתר

אופציונלי: סוד בשם `CF_RADAR_TOKEN` (טוקן חינמי של Cloudflare Radar) מוסיף למפת הסייבר מדינות מקור ויעד של תקיפות.
